# 🏠 Руководство пользователя: Жорик (DRON X GENIE) v0.1.0

> Простая инструкция для установки и запуска. Без терминов — только действия.

---

## 📥 1. Как установить Жорика (3 шага)

### Шаг 1. Скачайте инсталлятор
- Файл: **`Zhorik-Setup-0.1.0.exe`**
- Размер: ~200–300 МБ
- Откройте файл (двойной клик).

### Шаг 2. Пройдите установку
1. Нажмите **«Далее»** → **«Принять лицензию»** → **«Далее»**.
2. Папка по умолчанию: `C:\Users\<ВашеИмя>\AppData\Local\Zhorik\` — **не меняйте**.
3. Нажмите **«Установить»**. Ждите 1–2 минуты.
4. В конце поставьте галочку **«Запустить настройку окружения сейчас»** и нажмите **Готово**.

> ⚡ *Если галочку сняли — не страшно. Запустите ярлык «Жорик» из Пуска позже — он сам всё настроит.*

### Шаг 3. Дождитесь настройки (первый запуск)
Откроется синее окно PowerShell:
```
[1/3] Checking and creating virtual environment .venv...
[2/3] Installing dependencies from requirements.txt...
[3/3] Starting backend at http://127.0.0.1:8000...
```
- **Не закрывайте окно!** Оно само закроется, когда всё будет готово.
- Если интернета нет — появится жёлтое предупреждение, но установка продолжится (используются уже скачанные пакеты).

## ✅ 2. Как проверить, что всё работает

После настройки автоматически откроется браузер на странице:
```
http://localhost:8000/vault/frontend/dron_ui/tv_main.html
```

**Чеклист «Всё работает»:**

| ✅ | Проверка | Как проверить |
|---|----------|---------------|
| 1 | Бэкенд жив | В браузере откройте `http://localhost:8000/api/health` → должно быть `{"status": "ok"}` |
| 2 | Интерфейс открылся | Видите чат, часы, кнопки «Дрон», «Джин», «X» |
| 3 | Дрон отвечает | Напишите в чате: `Дрон, привет` → должен ответить |
| 4 | Голос работает | Нажмите 🔈 у сообщения Дрона → услышите голос |
| 5 | Переключение режимов | Отключите интернет → напишите Дрону → ответ станет короче (2-3 фразы) |

## 🌐 3. Два режима Дрона (важно!)

| Режим | Когда | Как отвечает Дрон | Лог в консоли |
|-------|-------|-------------------|---------------|
| **CLOUD_LIVE** | Интернет **есть** | Подробно, с эмпатией, использует полную память Obsidian | `[DRON] Mode switched to CLOUD_LIVE` |
| **LOCAL_OFFLINE** | Интернета **нет** | Кратко (2-3 фразы), тёплый тон, сложное: «Нужен интернет» | `[DRON] Mode switched to LOCAL_OFFLINE` |

> **Не переживайте, если интернет пропал** — Жорик сам переключится в экономный режим. Когда интернет вернётся — вернётся и полный режим (через ~1 минуту).

---

## 🎙 4. Голос Дрона

- Голос **один и тот же** в обоих режимах (не меняется).
- Настройка голоса: в интерфейсе → ⚙️ Настройки → «Голос Дрона» → выбрать модель → Сохранить.
- Если голос не слышен: проверьте громкость системы и браузера.

## 🛠 5. Типичные проблемы и решения

| Проблема | Решение |
|----------|---------|
| «Инсталлятор не запускается» | Нажмите ПКМ → «Запуск от имени администратора» |
| «Ошибка при установке зависимостей» | Проверьте интернет. Если интернета нет — это нормально, жмите «Продолжить» |
| «Бэкенд не запускается (порт 8000 занят)» | Закройте другие программы на порту 8000. Перезапустите лаунчер. |
| «Дрон не отвечает» | Проверьте `http://localhost:8000/api/health`. Если не `ok` — перезапустите лаунчер. |
| «Нет голоса» | В настройках включите «Автовоспроизведение голоса». Проверьте модель голоса. |

## 📁 6. Где лежат файлы

| Что | Где |
|-----|-----|
| Программа | `%LOCALAPPDATA%\Zhorik\` |
| Настройки и память | `%LOCALAPPDATA%\Zhorik\data\` |
| Логи | `%LOCALAPPDATA%\Zhorik\data\logs\` |
| Виртуальное окружение | `%LOCALAPPDATA%\Zhorik\.venv\` |

> **Не удаляйте папку `%LOCALAPPDATA%\Zhorik\`** — там вся память и настройки.
> Для полной переустановки — удалите эту папку и запустите инсталлятор заново.
