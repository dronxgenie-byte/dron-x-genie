# 📦 Offline Setup — Установка модели LFM3-1.7B без интернета

> Инструкция для машин **без интернета** или с ограниченным доступом.
> Модель весит ~1 GB (Q4_K_M). Скачайте заранее на другой машине и перенесите флешкой.

---

## 🎯 Что нужно

| Файл | Размер | Откуда скачать |
|------|--------|----------------|
| `LFM3-1.7B-Q4_K_M.gguf` | ~1024 MB | https://huggingface.co/LiquidAI/LFM3-1.7B-GGUF/resolve/main/LFM3-1.7B-Q4_K_M.gguf |

---

## 📂 Куда положить

1. Откройте папку установки Жорика:
   ```
   %LOCALAPPDATA%\Zhorik\
   ```
   (Win+R → вставьте путь → Enter)

2. Создайте папку `models` (если нет):
   ```
   %LOCALAPPDATA%\Zhorik\models\
   ```

3. Положите туда файл `LFM3-1.7B-Q4_K_M.gguf`.

4. Создайте пустой файл-флаг `.model_ready` в той же папке:
   - Правой кнопкой → Создать → Текстовый документ
   - Имя: `.model_ready` (с точкой в начале, без расширения `.txt`)
   - Если спрашивает «Изменить расширение?» — **Да**.

---

## ✅ Проверка

Структура должна быть:
```
%LOCALAPPDATA%\Zhorik\
├── models\
│   ├── LFM3-1.7B-Q4_K_M.gguf     (~1 GB)
│   └── .model_ready              (пустой файл, 0 байт)
├── backend\
├── scripts\
└── ...
```

---

## 🚀 Автоматическая загрузка (если интернет появится)

Если интернет появится позже, скрипт `scripts/download_lfm3.ps1` сам скачает модель при первом запуске лаунчера. Ручная установка нужна только для **полностью офлайн** машин.

---

## 🔧 Для LM Studio (если используете GUI)

1. Откройте LM Studio.
2. Вкладка **My Models** → **Add Model** → укажите файл `%LOCALAPPDATA%\Zhorik\models\LFM3-1.7B-Q4_K_M.gguf`.
3. Загрузите модель («Load Model») с настройками:
   - GPU: Max / All layers
   - Context: 8192
4. В лаунчере Жорика модель подхватится автоматически (ключ `MODEL_KEY` в `scripts/launcher.py`).

---

## ❓ Частые вопросы

| Вопрос | Ответ |
|--------|-------|
| Можно ли использовать другую квантовку? | Да, но Q4_K_M — оптимальный баланс скорость/качество для 1.7B. Q8_0 быстрее на CPU, но весит 2× больше. |
| Где менять модель в коде? | `scripts/launcher.py` → переменная `MODEL_KEY` (для `lms load`). |
| Модель не загружается в LM Studio | Проверьте версию LM Studio (нужна ≥ 0.3.0). Обновите. |
| Файл `.model_ready` не создаётся | Создайте вручную: правая кнопка → Новый → Текстовый документ → имя `.model_ready` → Enter → «Да». |
